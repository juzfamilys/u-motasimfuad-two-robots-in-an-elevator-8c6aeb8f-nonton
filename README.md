One original funny line about two robots stuck in an elevator together: one robot tries to stay calm with a very confident claim, the other points out the obvious flaw, and the elevator itself refuses to help.

> Robot one whispered, "Don't panic, I know every floor," and robot two replied, "Great, then tell the doors," and the elevator stayed silent.

140 characters. How it works: main.py validates the line, writes it to entry.txt with no trailing newline, then reads it back and re-validates the exact bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
